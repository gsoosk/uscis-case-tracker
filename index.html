How this tracker works

100% Privacy-Focused. Your data never leaves your browser — everything is stored locally, with no account, server, or tracking.
  1. Add your receipt number — we open the official USCIS case-status API in a new tab.
  2. Log in to myaccount.uscis.gov if asked, then copy the JSON you see.
  3. Paste it back here to save a timestamped snapshot.
  4. Repeat any time to build a timeline and catch changes between snapshots.

Event codes and status explanations shown in the timeline are based on publicly documented USCIS/NIEM case-status codes, not official USCIS guidance.

Immigration Forms Supported

    

      Our USCIS tracker supports all immigration forms including: I-485 Adjustment of Status (Green Card),
      I-765 Employment Authorization Document (Work Permit/EAD), I-131 Travel Document (Advance Parole/Re-entry Permit),
      I-140 Immigrant Worker Petition, I-130 Family-Based Immigration Petition, N-400 Naturalization Application (Citizenship),
      I-129 Nonimmigrant Worker Petition (H-1B, L-1), I-129F Fiancé Visa, I-90 Green Card Renewal, I-751 Remove Conditions on Residence,
      I-539 Extension/Change of Status, and all other USCIS case types.
